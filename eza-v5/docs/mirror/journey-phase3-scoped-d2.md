# Journey Phase 3 — Scoped D2

Status: implementation complete (fail-closed Journey window meaning).

## Invariant

A published Journey V1 Yansı derives **all semantic meaning** from its confirmed exact 8 Q/A window.

Outside-window conversation content must not influence:

- D1 context
- D2 interpretation
- Semantic Anchors
- Curiosity Builder / public landing
- image / mapped prompt
- Narrative Alignment hard claims

## Canonical input

```
ConfirmedJourneyWindow {
  journeyId, sourceConversationId, parentJourneyId?,
  windowIndex, windowStart, windowEnd,
  selectedSteps[8]
}
```

After Review 8 confirmation, the selected-step snapshot is frozen for that journey version. Later Q9+ messages must not mutate scoped hashes.

## Flow

```
Confirmed 8 → Scoped D1 messages (16 turns) → D2 prepare
            → Anchors (anchorsScope=journey_window_v1)
            → Curiosity / publicTitle / publicSummary
            → mapped prompt
            → Narrative Alignment (claims from scoped lineage only)
```

Legacy Conversation Mirror (flag off) keeps full-chat prepare behavior.

## Fail-closed

Malformed or missing Journey scope → `journey_semantic_scope_invalid`.  
No silent fallback to full conversation.

## Cache isolation

Prepare `scope_key` appends `journey:{id}:v{version}:{windowHash}`.  
Scoped `contentHash` is computed from the 16 scoped turns only (title/summary stripped when scope is bound).

## Observability (no private text)

Logged/persisted lineage fields:

- journeyId, journeyVersion, sourceConversationId
- windowIndex, windowHash, semanticScope
- scopedInputHash
- (downstream) interpretation / anchors / landing / mapped / provider hashes when available
